## Реализовано

- [x] **«Поток» — чат-подобная лента.** Синтетический peer `SyncGramStreamChat` (`Namespaces.Peer.Empty`), строка вставляется в `chatListNodeEntriesForView` для главной вкладки, нажатие перехватывается в `ChatListController` и открывает `SyncGramStreamController`. Экран — переписка: шапка с аватаром и счётчиком чатов, пузыри с **именем реального автора**, аватаркой (`AvatarNode`), контекстом чата и временем, разделители дат, нижняя панель выбора чатов. Медиа показываются по типу (фото/видео/файл/голос/стикер/опрос), топики супергрупп открываются через `navigateToForumThread`. Раскладка ручная (`layout(in:)`), поэтому тексты не накладываются.
- [x] **Выбор чатов для Потока.** Экран `SyncGramStreamChatsController` переписан с ручной раскладкой: кнопки «Выбрать все»/«Снять все» стоят отдельным рядом и не накладываются при пустом списке; список обновляется по `streamSelectionChanged` и при каждом появлении экрана, поэтому чаты появляются с первого открытия.
- [x] **Скрыть «Поток» из списка чатов.** Настройка `streamEnabled` (по умолчанию включена) и тумблер «Показывать «Поток»»; при переключении список чатов перестраивается сразу.
- [x] **Импорт сессии без «вечного обновления» (root cause).** `AccountStateManager` больше не выпускает первый `pollDifference` до `network.shouldKeepConnection == true`, а `reset()` действительно отменяет зависшую операцию (disposable сохраняется, running-операция снимается) — раньше `reset()` был no-op и все «страховки» не работали. Отложенный первый синк применяется только к аккаунту, импортированному в текущем процессе (`SharedAccountContext.markAccountAsImported`), а не ко всем записям с атрибутом `backupData`; на холодном старте ожидания нет. UI-сторожа с `exit(0)` и конфликтующими таймаутами удалены. После создания контекста записи аккаунта из metadata вычищается permanent auth key: остаются только `peerIdentity` и `notificationKeys` для push-расширения. Чат-лист перевыравнивается по позиции «список в самом верху» (считается до применения нового инсета), без липкого `hasUserScrolled` и с guard на inline-режим.
- [x] **Полный импорт сессии.** Файл теперь содержит `AccountBackupData` из `accountBackupData(postbox:)`; при импорте `syncGramImportSession` создаёт запись аккаунта с auth key и вызывает `switchToAccount`, то есть выполняется полноценный вход, а не только восстановление настроек. Старые файлы без ключей импортируют только настройки.
- [x] **Удалённые сообщения приглушены и помечены.** `SyncGramDeletedMessageAttribute` и `SyncGramEditHistoryAttribute` зарегистрированы в `AccountManager` через `declareEncodable` — без этого Postbox выбрасывал их при чтении из базы. Метка удаления включена по умолчанию, `mainContainerNode.alpha = 0.62` для `isSyncGramDeleted`, иконка мусорки (`trash`) рисуется на месте метки «изменено» во всех типах пузырей (текст, медиа, стикеры, опросы и т.д.), а «изменено» рядом с мусоркой не дублируется.
- [x] **Уведомления об удалённых и об окончании подписи удалены.** Удалён вызов `SyncGramNotifications.notifyDeletedMessage`, сам файл уведомлений удалён, из `SyncGramSigningInfo` убрано планирование `UNCalendarNotificationTrigger`; соответствующие тумблеры и ключи настроек убраны.
- [x] **Пилюля-уведомление.** `SyncGramToast`: выезжает снизу вверх, векторная галочка, автоскрытие 2.6 с, свайп вниз, вне пилюли касания проходят в UI. Подключено к копированию username и «Прочитать все».
- [x] **Превью размера списка чатов.** Убран фиктивный элемент «Открыть», строка масштабируется вокруг центра, убран хак с `anchorPoint (0,0)`, из-за которого превью уезжало.
- [x] **Экспорт/импорт сессии.** `SyncGramSessionArchive`: JSON-заголовок с контрольным вопросом, PBKDF2-HMAC-SHA256 (600 000 итераций), AES-256-GCM; ответ нигде не сохраняется, неверный ответ отсекается тегом GCM. UI — «Сессия аккаунта» в настройках (экспорт через document picker, импорт с вопросом и ответом) и кнопка «Сессия» на экране входа, которая расшифровывает файл и восстанавливает настройки SyncGram до входа.

- [x] **Уведомления в фоне (вариант A).** `SyncGramBackgroundNotifications`: при фоновом обновлении читает непрочитанные по всем аккаунтам, сравнивает с сохранённым снимком и показывает локальное уведомление «N новых сообщений» (с учётом склонений), отдельный `threadIdentifier` на аккаунт, звук, без текста сообщений. Тумблер «Уведомления в фоне» переименован, при включении перерегистрирует `BGAppRefreshTask`. Учитывает несколько аккаунтов.

- [x] **Ответ на удалённое сообщение.** При реплае на удалённое сообщение в исходящий текст вставляется blockquote с подписью автора и реальным текстом удалённого сообщения, ниже — ответ пользователя. Reply subject на сервер не отправляется, поэтому Telegram не может выбросить цитату; entities пересчитываются уже по итоговой строке.
- [x] **Ширина карточек настроек.** В панели аккаунтов строка действий больше не выходит за карточку: `trailing` закреплён равенством, кнопки делят ширину поровну, включены `adjustsFontSizeToFitWidth` и `clipsToBounds`.
- [x] **Блоки настроек без тёмных краёв.** Элементы списка переведены с `.glass` на `.legacy`, а `withModalBlocksBackground()` убран: маска скруглений больше не рисует тёмные полосы по бокам и не создаёт ощущение панелей за экраном.
- [x] **Живой фон-шейдер.** Новый модуль `SyncGramUI`: `SyncGramShaderView` (Metal, 30 fps, пауза вне экрана и в фоне, снижение скорости при Reduce Motion) и `SyncGramShaderNode`/`SyncGramShaderBackdrop` для Texture- и UIKit-экранов. Пять стилей: «Аврора», «Волны», «Узор», «Пузыри», «Дюны»; палитра тёплая (медь, хвоя, песок), подстраивается под тёмную/светлую тему и акцент темы. Включён в списке чатов, чатах, `ItemList`-экранах и кастомных экранах SyncGram. Настройки: тумблер «Живой фон» и экран «Стиль фона» с живым превью (фон обновляется сразу при выборе).
- [x] **Живой фон в списках «Избранное» и «Архив».** `SyncGramShaderNode` теперь живёт прямо в `ChatListNode` (нижайший subnode, только для режима `.chatList`), поэтому анимированный фон виден за строками любого списка чатов — главного, «Избранного», «Архива» и вкладок папок. Закреплённые строки «Избранное»/«Архив» при включённом шейдере рисуются полупрозрачным тинтом (`pinnedItemBackgroundColor` с alpha 0.35) вместо сплошного блока, overscroll-подложка списка — тоже.
